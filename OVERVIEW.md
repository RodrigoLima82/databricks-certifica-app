# Certifica — Product Overview

**Certifica** is a multi-tenant SaaS platform that turns Databricks certification
preparation into a complete, guided learning journey. Each customer (tenant) gets a
fully branded space — its own colors, logo, users, program and rankings — while sharing
a common engine and question bank. It runs on **Databricks Apps** (FastAPI + React),
stores data in **Databricks Lakebase** (Postgres), and uses the **Databricks Foundation
Model API** (Claude) to generate practice questions.

> Model: one app serves many clients — each tenant with its own identity (colors, logo,
> users, program and rankings), all from a single deploy.

---

## What it does

It guides each learner through the full path to certification and ties every activity
into measurable progress:

```
PROGRAM  →  LEARN (paths & classes)  →  PRACTICE (mock exams + flashcards)  →  CERTIFY
   └────────── progress bar + live leaderboard fed by real activity ───────────┘
```

The practice exam is positioned as **one step within the whole program**, not the entire
experience.

## Main features

### Multi-tenancy & white-label branding
- **Row-level multi-tenancy**: one app + one database serve unlimited tenants; users,
  results and progress are isolated per `tenant_id`. The certification question bank is
  global and shared.
- **Per-tenant branding applied at runtime**: each tenant has its own primary color and
  logo (uploadable SVG/PNG). A single build serves every client — no rebuild per customer.
- **"Find your workspace" entry**: the neutral landing resolves a company by name or
  identifier and routes to its branded login (`/t/<slug>`).
- **Self-service onboarding** (`/signup`) or admin-provisioned tenants.

### Program page (post-login home), editable per tenant
- A rich, customizable program landing: headline, intro, KPIs, value pillars, a
  **4-step roadmap** (Learn → Practice → Certify → Impact), resources, and a ranking section.
- **"How to take your certification"** section with the exam logistics: proctored exam
  facts (questions, duration, languages, validity), the step-by-step registration flow
  (Webassessor), proctoring requirements, results and retake policy.
- **Personal progress bar**: a single percentage combining classes completed and
  certifications passed.

### Learning paths & classes (real Databricks Academy catalog)
- Per-tenant **learning paths** mapped to a target certification, with classes grouped by
  level (Fundamentals / Associate / Professional), each showing duration and a **direct
  link to the real eLearning** course on Databricks Academy.
- **Certification details per path**: official exam format and the **syllabus with domain
  weightings** (e.g., ML Associate: Databricks ML 38%, Model Development 31%…), plus the
  official exam guide PDF.
- Learners **mark classes as completed** → updates their progress and feeds the leaderboard.

### Practice (mock exams + flashcards)
- Configurable mock exams (5–60 questions, by topic), with grading, per-question
  explanations, per-topic breakdown, and a reviewable answer sheet.
- **AI-generated questions** on demand via the Databricks Foundation Model API (Claude).
- **Flashcards** for quick, interactive review.
- **Attempt history** and **PDF/CSV export** of results.

### Gamification & tracking
- **Live leaderboard** per tenant computed from real data — points from best score per
  certification plus completed classes; highlights the current user.
- Per-user progress across the whole program.

### Administration (three levels)
- **Platform console** (`/platform`, super-admin): manage tenants (create, suspend/activate,
  open, edit branding/program/paths) and manage console operators.
- **Tenant admin** (`/admin`): manage the company's users (create, edit name/area, change
  password, suspend/activate, delete), see tracking, and export reports.
- **Learner**: self-register (if enabled), take exams, track progress.

### Internationalization
- Full UI in **Spanish, Portuguese and English** with an in-app language switcher;
  locale-aware dates. One build serves all languages.

## Advantages

- **Sell once, deploy once, serve many.** New customers are added in minutes (a row +
  branding), not a new codebase or deployment per client.
- **Truly white-label.** Each tenant looks like its own product (color + logo + program),
  yet upgrades roll out to everyone from a single deploy.
- **Real, official content.** Learning paths link to the actual Databricks Academy courses
  and official exam guides; exam logistics and domain weightings come straight from the
  certification guides.
- **AI-powered practice.** Fresh, scenario-style questions generated by Claude through the
  Databricks Foundation Model API — no external LLM keys or services.
- **End-to-end learning loop.** Study (paths/classes) → practice (mock exams/flashcards) →
  certify (Webassessor) → measurable progress and ranking — the exam is part of the whole.
- **Engagement built in.** Progress bars and a live leaderboard turn preparation into a
  motivating, trackable program.
- **Native to Databricks.** Runs on Databricks Apps with Lakebase and Foundation Model
  APIs — secrets stay in the workspace, identity via the app service principal, no extra
  cloud infrastructure required.
- **Portable.** A clean data-access layer also supports an AWS deployment path (RDS +
  App Runner + Amplify) if a customer ever needs to run it outside Databricks.
- **Multilingual** out of the box for LATAM + Brazil + global teams.

## Architecture at a glance

| Layer | Technology |
|---|---|
| Frontend | React + TypeScript + Vite (served by the backend) |
| Backend | FastAPI (Python) on **Databricks Apps** |
| Data | **Databricks Lakebase** (Postgres), row-level multi-tenant |
| AI | **Databricks Foundation Model API** (Claude) for question generation |
| Auth | JWT + bcrypt; tenant + roles in the token; PG native login to Lakebase |
| Exam registration | Webassessor (linked) · credentials on credentials.databricks.com |

**Roles:** super-admin / operator (platform) · tenant admin · learner.
